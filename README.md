# 📊 Data Professional Survey Analytics Dashboard

## 1. Project Title / Headline

### 📊 Data Professional Survey Analytics Dashboard

An interactive Power BI dashboard designed to analyze survey data from data professionals, focusing on **job roles, salaries, programming languages, work experience, job satisfaction, and geographic distribution**.

---

## 2. Short Description / Purpose

The Data Professional Survey Dashboard is an interactive **Power BI report** created to transform survey responses from data professionals into meaningful and easy-to-understand insights. The dashboard helps explore career trends, salary patterns, programming language preferences, and overall job satisfaction within the data industry.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 **Power BI Desktop** – Main data visualization and dashboard development platform.
* 📂 **Power Query** – Used for data cleaning, transformation, and preparation.
* 🧠 **DAX** – Used to create calculated measures and KPIs.
* 📈 **Data Visualization** – Used charts, cards, slicers, and interactive visuals to present insights.
* 🗂️ **Data Modeling** – Used to structure the survey data for analysis and interactive filtering.
* 📁 **File Format** – `.pbix` for Power BI development and `.png` for dashboard previews.

---

## 4. Data Source

The project uses a **Data Professional Survey dataset** containing responses from professionals working in the data industry.

The dataset includes information such as:

* Job title / role
* Salary
* Country
* Years of experience
* Programming languages
* Job satisfaction
* Work-life balance
* Difficulty of entering the data profession
* Preferred programming languages and technologies

The survey provides an overview of the career experiences, skills, preferences, and challenges faced by data professionals.

---

## 5. Features / Highlights

### • Business Problem

The data industry includes various roles, technologies, salary levels, and career paths. However, analyzing raw survey responses can make it difficult to identify **salary trends, popular programming languages, career preferences, and job satisfaction levels**.

### • Goal of the Dashboard

The goal of this dashboard is to provide an interactive visual analysis that helps users:

* Explore different data-related job roles.
* Compare salary patterns across professionals.
* Identify popular programming languages.
* Analyze job satisfaction and work-life balance.
* Understand the geographic distribution of respondents.
* Explore trends within the data profession.

### • Walkthrough of Key Visuals

* **Key KPIs**
  Displays important summary metrics from the survey, providing a quick overview of the dataset.

* **Data Professional Roles**
  Shows the distribution of respondents across different data-related job titles.

* **Salary Analysis**
  Provides insights into salary levels across different professional roles.

* **Programming Language Analysis**
  Highlights the most popular programming languages used by data professionals.

* **Country Analysis**
  Shows the geographic distribution of survey participants and allows users to explore responses by location.

* **Job Satisfaction**
  Analyzes overall satisfaction levels among data professionals.

* **Work-Life Balance**
  Provides insights into how professionals rate their work-life balance.

* **Interactive Slicers**
  Allows users to filter the dashboard and explore specific segments of the survey data.

### • Key Insights

The dashboard helps identify:

* Salary differences across data-related roles.
* The most commonly used programming languages.
* Job satisfaction trends among data professionals.
* Work-life balance patterns.
* Geographic distribution of professionals.
* Career and experience trends within the data industry.

### • Business / Career Impact

**Career Planning:** Helps aspiring data professionals understand different roles, skills, and salary trends.

**Skill Development:** Programming-language insights can help identify commonly used technologies and guide learning priorities.

**Industry Analysis:** Provides an overview of trends and characteristics within the data profession.

**Data-Driven Decision Making:** Demonstrates how raw survey data can be transformed into actionable insights using Power BI.
